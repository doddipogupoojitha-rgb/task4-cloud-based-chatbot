# Task 4 - Cloud-Based ChatBot

Create and deploy chatbot using cloud services for automated user interactions.

## Objective
Chatbot design, cloud integration, scalable deployment

## Features
- Flask + Intent JSON (like Dialogflow)
- Cloud-ready deployment (Render/Heroku)
- Chat UI for automated support

## Tech Stack
Python, Flask, Cloud, HTML/CSS/JS

## Real-World Use
Automated customer support, Virtual assistants

## How to Run
pip install -r requirements.txt
python app.py
